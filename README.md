# cps-irc-app

Native and terminal IRC applications built with the CPS libraries.

## Install

```sh
nimble install https://github.com/gabearro/cps-irc-app@#v1.0.0
```

Dependencies are resolved automatically by Nimble: `cps-runtime`, `cps-tls`, `cps-irc`, `cps-irc-bouncer`, `cps-tui`, `cps-native-gui`.

## Development

```sh
nimble install -d -y
nimble test
```

This repository was extracted from [gabearro/cps-runtime](https://github.com/gabearro/cps-runtime) with its relevant Git history preserved.
